
# WiKiLegends

## Description

WiKiLegends is a project inspired by the game League of Legends. It functions as a wiki, providing game-related data and insights using the Riot Developer API. The application showcases various features and details about the champions.

## Features

- **Champion Information**: Displays detailed data about each champion.
- **Responsive Design**: Tailored for a seamless experience on all devices.
- **TailwindCSS Styling**: A modern and efficient styling approach.
